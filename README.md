# React и API

Интерактивная лекция на русском языке: 70 минут материала и задание на 20 минут практики.

[Открыть лекцию](https://ngg-dev.github.io/react-api-lecture/)

Продолжение [первой лекции о React](https://ngg-dev.github.io/react-lecture/). Пример развивается вокруг каталога книг.

## Запуск

```sh
npm run dev
```

Откройте http://127.0.0.1:4187. Для локального сервера нужен Python 3. Готовая сборка уже включена; после изменений исходников выполните `npm install` и `npm run build`.

```sh
npm run check
npm run build
```

Папка `dist` содержит статический сайт, который можно разместить на GitHub Pages или другом статическом хостинге. Лекцию также можно открыть из `index.html` без сервера. Встроенные демонстрации работают локально и не обращаются к внешним API.

## Публикация

GitHub Pages публикует корень ветки `main`. После изменения исходников выполните `npm run check` и `npm run build`, затем закоммитьте исходники вместе с обновлённым `app.js` и отправьте изменения в `main`. Файл `.nojekyll` отключает обработку сайта Jekyll.

## Файлы

- `content.js` — содержание слайдов, тайминг, сценарий докладчика и ссылки на документацию.
- `src/App.jsx` — React-оболочка: навигация, оглавление и жизненный цикл слайда.
- `src/slide-renderer.js` и `styles.css` — отображение содержания слайдов.
- `app.js` — готовый браузерный bundle (пересобирается через `npm run build`).
- `catalog-demo.js` — один каталог на трех этапах: локальные книги, запрос по кнопке, запрос при появлении.
- `src/catalog-story.js` — схемы «массив → JSX → карточки».
- `src/api-diagrams.js` — схемы общего HTTP-клиента и пути запроса.
- `keys-demo.js` — визуальное сравнение стабильного id и индекса.
- `demos.js` — подключение демонстраций и архитектура проекта.

Финальный блок «Где взять API для текущей лабораторной работы» предлагает три источника: готовое публичное API без секретного ключа, свой backend на Node.js с одним GET и заранее заданными данными или HTTP API на Java из курсовой/лабораторной либо нового проекта. Начать можно без базы данных. На занятиях по Node.js готовое API и Java-backend можно дополнить серверной прослойкой, а собственный сервер — базой данных.

DummyJSON показан как источник товаров с ответом `{ products: [...] }`, а не готовый каталог книг или `/api/books`. В первом варианте текущая лабораторная полностью использует готовое публичное API напрямую из React. Прослойку можно добавить позже, когда начнутся лабораторные по API на Node.js. На этом серверном этапе можно также подключить DeepSeek или другие источники; секретные ключи остаются на сервере.

Код на слайдах и оболочка лекции используют React. Готовая сборка открывается без доступа к CDN. Демо снабжены подписью учебной модели и работают без внешнего API.

Материал развивается последовательно: задача каталога → карточка → локальный массив → список и key → запрос по кнопке → состояния интерфейса → знакомство с useEffect → собственный useBooks и reload → отдельный API-слой → общий клиент на fetch или Axios → выбор API для текущей лабораторной работы. Основы fetch считаются знакомыми; Axios показан как альтернатива общему клиенту на fetch.
