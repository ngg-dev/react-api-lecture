# React и API

Интерактивная лекция на русском языке: 70 минут материала и задание на 20 минут практики.

Продолжение [первой лекции о React](https://ngg-dev.github.io/react-lecture/). Пример развивается вокруг каталога книг.

## Запуск

```sh
npm run dev
```

Откройте http://127.0.0.1:4173. Зависимости npm устанавливать не требуется. Для локального сервера нужен Python 3.

```sh
npm run check
npm run build
```

Папка `dist` содержит статический сайт, который можно разместить на GitHub Pages или другом статическом хостинге. Лекцию также можно открыть из `index.html` без сервера. Встроенные демонстрации работают локально и не обращаются к внешним API.

## Файлы

- `content.js` — содержание слайдов, тайминг, сценарий докладчика и ссылки на документацию.
- `app.js` и `styles.css` — интерфейс лекции.
- `demos.js` — учебные симуляции запросов, эффектов, гонок и архитектуры проекта.

Финальный блок показывает варианты семестрового проекта: готовое API, Node.js как прослойка к внешнему API, собственный сервер с базой данных и Node.js как адаптер к HTTP API Java-лабораторной. Это альтернативы, а не обязательные части одного проекта.

Код на слайдах показывает React. Оболочка самой лекции написана без фреймворка, чтобы её можно было открыть без установки пакетов и доступа к CDN.
